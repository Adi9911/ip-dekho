What Is My IP Address? Understanding Public and Private IP

Every device that connects to the internet needs a unique address. This is called an IP address. When you search what is my IP or check my IP, you are looking for your public address assigned by your ISP. This page shows it instantly, along with your location, ISP, and timezone.

What is a Public IP Address?

Your public IP is the address the internet sees. Websites, apps, and servers use it to send data back to you. It can reveal your approximate city, region, and ISP — which is exactly what we display at the top. Most home connections use a dynamic IP that changes, while businesses often use a static IP for hosting and remote access.

What is a Private IP Address?

A private IP is used inside your home or office network. Your router assigns addresses like 192.168.x.x or 10.x.x.x to phones, laptops, and smart devices. These addresses are not visible on the internet and work only locally. Your router uses NAT to share one public IP among many devices.

Public vs Private IP

Think of it this way: public IP is global and unique, private IP is local and reusable. Public IP helps networks talk to each other, private IP helps devices talk within the same network. If your internet is down, checking the public IP tells you if the ISP link is working.

How to Check My IP Address?

Our tool uses accurate databases like ipinfo.io and ipapi.co to detect your IP, location, and ISP automatically. You can also find your private IP manually with ipconfig on Windows or ifconfig on Mac/Linux. We also try to detect it via WebRTC directly in the browser.

Internet Speed Test

Along with IP details, we provide a fast internet speed test powered by Cloudflare. It measures download speed for streaming and browsing, upload speed for video calls and backups, ping for latency, and jitter for stability. Running it regularly helps you verify if you are getting the speed promised by your ISP.
